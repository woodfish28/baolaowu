# 老余数字人 · IMA 原生技能包（v2.3.1）

> 保来屋保险经纪人余仁哲的对话分身。**不需要任何云端后端**——在你自己的 WorkBuddy 里、
> 连你自己的 IMA 知识库运行；没配 IMA 也能用内置的离线快照。
>
> 检索优先级与云端 `index.py` 完全一致：
> **产品库 ＞ 保来屋经纪 ＞ 保知堂 ＞ 保险业干货 ＞ 离线快照 ＞ 联网兜底**

## 三步装好

1. **解压**：把 `skills/` 下的四个目录解压到 `~/.workbuddy/skills/`
   （或项目级 `<workspace>/.workbuddy/skills/`）。
2. **（可选）连接 IMA**：在 WorkBuddy 连接器里连「ima知识库」。不连也能用，走离线快照。
3. **验证**：命令行跑一次 `python scripts/kb_search.py "护工卡"`，能出结果就说明装好了。

## 知识库：能不能自动安装？

**不能。** IMA 的知识库是绑定账号的云端资源，OpenAPI 只有检索/列出/导入内容的接口，
**没有创建知识库、也没有把库授权给他人的接口**。任何技能包都塞不进一个"知识库"实体。

三条可行路线，详见 `references/offline-kb.md`：

| 路线 | 你要做什么 | 代价 |
|---|---|---|
| **A 加入共享库**（推荐） | 点开 `config.json → kb_share_links` 里的链接并加入 | 无。内容自动与作者同步 |
| **B 自建** | 在自己 IMA 建四个同名库并灌内容，改 `config.json` 的 id | 要自己维护内容 |
| **C 离线快照**（零配置） | 什么都不做，直接用你自己的 `data/`（自行导出） | 产品库那层是空的，且内容截至 2026-08-16 |

## 离线兜底怎么用

```bash
python scripts/kb_search.py "甲状腺结节 买什么医疗险"
python scripts/kb_search.py "护工卡" --top 3
python scripts/kb_search.py "重疾险 误区" --kb baolaowu
python scripts/kb_search.py "重疾险保额" --full
python scripts/kb_search.py "护工卡" --json
```

参数：`--kb`（baolaowu / baozhitang / industry / all）、`--top`（1–20，默认 5）、
`--full` 完整正文、`--json` 机器可读、`--snap-date` 打印快照日期。
退出码 `0` 有结果，`1` 未命中（此时才该联网兜底）。

**别直接读 `data/*.json`（如有导出）**——567 篇全进上下文会撑爆窗口。

**硬边界**：产品库（条款/费率/核保规则/在售状态）不在你导出的离线快照里。查不到就明说
「以官方当前公布为准」，**不许推测数字**。

## 注意事项

  最终以保险公司核保结论与官方条款为准。

  本包定位是"在自己 WorkBuddy 里用"。
