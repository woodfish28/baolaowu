# 发布共享知识库（分享者操作指南）

> **这篇是给老余（分享者）看的。** 接收方不需要看这篇。
>
> 做完这篇的 5 分钟操作，对方就能一键拿到你的四个知识库，且内容**永远与你同步**。

---

## 为什么要做这件事

技能包里的 `config.json` 写的是**你 IMA 账户下**的四个知识库 id：

| 知识库 | id |
|---|---|
| 产品库 | `7328950120379741` |
| 保来屋经纪 | `7447277815732978` |
| 保知堂 | `7494240863002273` |
| 保险业干货 | `7346181717887705` |

这些 id 对别人**无效**——他们的 IMA 账号访问不到你的库。这就是对方反馈
"保知堂等知识库没有添加"的根因。

发布成共享知识库后，对方点链接加入，库就出现在他的 IMA 里，技能会自动按名称映射到
他那边的新 id。**内容还自动同步**——你往库里加新文章，他立刻能检索到，不用重新发技能包。

---

## 操作步骤（约 5 分钟）

### 1. 逐个库设为共享

在 IMA 里进入目标知识库 → 点右上「**分享**」/「**邀请协作**」→ 设置：

- **可见范围**：选「**公开**」或「凭链接加入」（别选「仅指定成员」，那样要你一个个加人）
- **加入方式**：选「**直接加入**」，免去你审批
- **成员权限**：选「**仅查看**」或「**可查看和保存**」。
  ⚠️ 别给「可编辑」，否则别人能删你的资料

> 若界面上没有把**已有个人库**直接转共享的入口（IMA 版本差异），则走这条路：
> 新建共享知识库 → 创建时选择「**从个人知识库导入**」，把原库内容搬过去。

### 2. 生成链接

点「**复制链接**」或「**生成知识码**」。四个库各拿一条。

### 3. 填进技能包

把链接填到 `skills/laoyu-digital-human/config.json` 的 `kb_share_links`：

```json
"kb_share_links": {
  "产品库": "https://ima.qq.com/...",
  "保来屋经纪": "https://ima.qq.com/...",
  "保知堂": "https://ima.qq.com/...",
  "保险业干货": "https://ima.qq.com/..."
}
```

填完**重新打包**再发出去。技能运行时会提示接收方点这些链接。

### 4.（可选）发布到知识库广场

PC 端：知识库顶部「···」→「权限设置」→ 勾选「**发布到广场**」。

好处：别人能搜到、能自助加入，你不用逐个发链接。
额外好处：官方说明提到，发布到广场后**不再占用你的个人云存储空间**。

---

## ⚠️ 发布前必须想清楚的一件事

**共享 = 库里的内容对加入者全部可见。** 请逐个库过一遍：

| 知识库 | 内容性质 | 建议 |
|---|---|---|
| 产品库 | 条款、渠道出单表、**佣金表**、核保规则 | 🔴 **谨慎**——渠道佣金属于商业敏感信息，建议不共享 |
| 保来屋经纪 | 公众号原创观点（本来就公开） | ✅ 可共享 |
| 保知堂 | 内部培训与合规参考 | 🟡 看内容敏感度，含内部资料的别共享 |
| 保险业干货 | 行业公开研究 | ✅ 可共享 |

**我的建议**：只共享【保来屋经纪】这一个库。它是老余观点的主力来源，本来就是公开发过的
公众号文章，共享它没有损失；而产品库的佣金表一旦公开，收不回来。

不共享的库，对方走**离线快照**兜底（需自行从 IMA 导出）。代价只是产品条款那一层查不到，
而这个技能本来也严格规定"条款以官方为准、不许推测数字"，所以降级是可控的。

---

## 如果只想给一个人用

不发布到广场，只把邀请链接私发给他就行。链接随时可以在权限设置里失效掉。

## 想撤回

知识库「···」→「权限设置」→ 关闭共享 / 转为私密。已加入的成员立刻失去访问权。
