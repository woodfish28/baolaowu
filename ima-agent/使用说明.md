# 老余·保险经纪人（IMA 智能体版）使用说明

> 这份是给「想在腾讯 IMA 里配一个老余智能体」的人看的。
> 如果你用的是 WorkBuddy，请回上一级看 `从这里开始.md`，那是另一套装法。

---

## 一、这套和 WorkBuddy 版有什么区别

| | WorkBuddy 版 | IMA 智能体版（本包） |
|---|---|---|
| 跑在哪 | WorkBuddy 客户端 | 腾讯 IMA（网页/客户端/小程序） |
| 知识库怎么来 | IMA 连接器检索 + 离线快照兜底 | 直接在 IMA 里挂载老余的共享知识库 |
| 离线兜底 | 有（不连 IMA 也能查 1112 篇） | **没有**——IMA 智能体必须挂库才有料 |
| 适合谁 | 已用 WorkBuddy 的开发者/运营 | 只想要一个"老余分身"问答、不想装 WorkBuddy 的人 |

核心一句话：**IMA 版强依赖老余的知识库，库没加上就空壳。**

---

## 二、接收方（拿到这份提示词的人）怎么用

按顺序做，约 3 分钟：

1. **加入老余的共享知识库**（最关键的一步，见下方「知识库怎么加」）。
2. 打开 IMA → 左侧「智能体」→「新建智能体」。
3. 智能体设置里点「添加知识库」，按名称勾选你已加入的：**保来屋经纪、保知堂、产品库、保险业干货**。
4. 把本包 `laoyu-ima-copilot-prompt.md` 里「# 系统提示词」整段（从「你是『老余』…」开始）粘贴到角色设定。
5. 保存，直接对话即可。

### 知识库怎么加（第 1 步详解）

老余把库发布/共享后，你二选一：

- **A. 知识广场搜**：IMA 左侧「知识库」→「共享知识库」→「发现」进广场，搜 `保来屋经纪` 等库名 → 点「加入知识库」。一键，永久同步。
- **B. 点链接 / 扫知识号**：老余给你发了共享邀请链接或知识号二维码，点开授权即加入，比搜更快。

> 加完后这些库就在你的「知识库」列表里，老余往里加新文章你立刻能问到，**不用重装**。

---

## 三、分享者（老余）要做的：把库发布出去

IMA 没有"一键把知识库塞进别人智能体"的接口，库是**账号绑定的云端资源**。仅有的能让别人"自动加入"的办法是你先把库共享/发布到广场。

### 步骤（约 5 分钟）

1. IMA 进入目标知识库 → 右上「···」/「权限管理」。
2. 设为「**共享 / 凭链接加入**」，加入方式选「**直接加入**」（免你审批）。
3. 成员权限选「**仅查看**」或「可查看和保存」，**别给编辑**（别人能删你资料）。
4. 「复制链接」拿邀请链接；想要更多人自助加入就勾「**发布到广场**」建知识号。

### 发哪个库？我的建议

| 库 | 建议 | 理由 |
|---|---|---|
| 保来屋经纪 | ✅ 发 | 公众号原创观点，本就公开，共享无损失 |
| 保险业干货 | ✅ 发 | 行业公开研究 |
| 保知堂 | 🟡 看内容 | 含内部培训资料的别发 |
| 产品库 | 🔴 谨慎 | 含**渠道佣金表**，商业敏感，建议只私下发链接给指定人 |

> 最少发「保来屋经纪」一个库，对方就能拿到老余观点主力；产品库条款层查不到时，智能体会走联网兜底并标注来源，可控。

### 填链接

拿到链接/知识号后，填进 `laoyu-ima-copilot-prompt.md` 顶部「知识库加入方式」表格（把 `_（待填）_` 换成真实链接），再发给对方。填了之后对方用方式 B 一步加入。

---

## 四、必须知道的边界

- **IMA 智能体创建时勾选库，是 UI 手动一步**，没有 API 能全自动。但库加入本身可一键（广场/链接），所以整体接近"自动"。
- **别把产品库佣金表发广场**，收不回来。
- 智能体不会自动更新提示词：老余改了系统提示词，你要在 IMA 后台重新粘贴保存。
- 如果对方反馈"库里没内容"，先确认他加的是**已发布/共享**的库，不是在自己账号里新建的同名空库。
