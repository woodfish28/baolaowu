# 知识库怎么配 + 离线兜底怎么用

> 这篇是给**接收方**看的。如果你拿到这个技能包后问「为什么检索不到东西」，看这里。

---

## 一、先说清楚：知识库装不进技能包

IMA 的知识库是**绑定 IMA 账号的云端资源**，不是一个能塞进 zip 的文件。它的 OpenAPI
只提供「检索 / 列出 / 导入内容」，**没有「创建知识库」接口**，也没有「把知识库授权给别
人」的接口。

所以：**任何技能包都不可能替你自动建好知识库。** 这不是打包方式的问题，是 IMA 的产品机制。

能自动的只有这三件事：

| 能自动 | 怎么自动 |
|---|---|
| 按名称找到你的知识库 id | 技能首次运行时列出你的全部知识库，按名字匹配，写回 `config.json` |
| 批量往已有库里灌内容 | IMA OpenAPI 的 `import_urls`（一次 1–10 个链接） |
| 完全不依赖 IMA 也能检索 | 用技能内置的离线快照，见第三节 |

## 二、三条路，按推荐程度排序

### 路线 A：加入作者发布的共享知识库（最省事，推荐）

作者在 IMA 里把四个库设成**共享知识库**，生成邀请链接或发布到「知识库广场」，
把地址填进本技能 `config.json` 的 `kb_share_links`。你要点开、加入，就这些。

**好处**：

- 零配置。加入后技能会自动按名称映射到你账号里的 id。
- 内容**永远跟作者同步**——老余往库里加新文章，你这边立刻能检索到。

**代价**：库里的内容对加入者可见。作者发布前需要确认：产品库里的渠道佣金表、
内部培训资料这类内容，是否适合对外。

> 若 `kb_share_links` 四项都是空的，说明作者还没发布共享库。找作者要链接，或走路线 B / C。

### 路线 B：用你自己的 IMA 账号自建

1. 在 IMA 里新建四个知识库，名字建议就叫：**产品库 / 保来屋经纪 / 保知堂 / 保险业干货**。
2. 往里灌内容。可以这样批量来：
   - 网页 / 公众号文章：IMA OpenAPI 的 `import_urls`，一次 1–10 个链接。
   - 本地 PDF / Word / PPT：`check_repeated_names` → `create_media` → COS 上传 → `add_knowledge`。
3. 让技能列出你的知识库，按名称匹配，把 id 写进 `config.json` 的 `kb_priority`。
   也可以自己填：`id` 是一串数字，在知识库页面的 URL 里能找到。

**适合**：你想建自己的保险知识库，只是借用了这套检索与应答逻辑。

### 路线 C：什么都不配，直接用离线快照

本包不再内置作者知识库快照（避免分发第三方文章语料）。你可从自己的 IMA 知识库导出快照放到 `data/`，实现离线检索。
跳到第三节。

## 三、离线兜底：没有 IMA 也能查老余观点

### 里面有什么

| 文件 | 内容 | 条数 |
|---|---|---|
| `data/wx_articles.json` | 保来屋经纪公众号文章（标题 + 摘要 + 原文链接） | 567 |
| `data/reference_baozhitang.json` | 保知堂（全文） | 10 |
| `data/reference_industry.json` | 保险业干货（全文） | 535 |

**快照日期以你导出时为准。** 静态快照会过期，注意时效。

### 怎么用

不要直接读 json——567 篇全读进上下文会撑爆。用配套的检索脚本：

```bash
python scripts/kb_search.py "甲状腺结节 买什么医疗险"
python scripts/kb_search.py "护工卡" --top 3
python scripts/kb_search.py "重疾险 误区" --kb baolaowu      # 限定库
python scripts/kb_search.py "重疾险保额" --full               # 看完整正文
python scripts/kb_search.py "护工卡" --json                   # 机器可读
```

参数：`--kb`（baolaowu / baozhitang / industry / all）、`--top`（1–20，默认 5）、
`--full`、`--json`、`--snap-date`。

退出码：`0` 有结果，`1` 一条都没命中（此时才该考虑联网兜底）。

脚本只用 Python 标准库，3.7+，无需 pip install。

### 硬边界（必须遵守）

1. **产品库不在你导出的离线快照里。** 条款、费率、核保规则、在售状态这些只存在于作者的 IMA 产品库。
   离线检索不到时，明说「具体条款以官方当前公布为准」，**不许凭记忆推测数字**。
2. **保知堂的内容不给用户原文链接**，只作内部框架参考——和 IMA 路线口径一致。
3. **标注时效。** 涉及费率、在售状态、政策时，提醒用户这是 2026-08-16 的快照，可能已变化。
4. 导出快照命中不了 ≠ 老余没写过。老余之后发的新文章不在里面，这时该说「我库里暂时没有」，
   而不是硬凑。

## 四、检索优先级（IMA 可用时）

| 层级 | 来源 | 权重 | 引用口径 |
|---|---|---|---|
| 1 | 产品库 | 4 | 「据产品库资料显示」——抠字眼、找原文，不改写一个数字 |
| 2 | 保来屋经纪 | 3 | 「老余观点 / 保来屋经纪认为」 |
| 3 | 保知堂 | 2 | 「内部参考」，**绝不外链** |
| 4 | 保险业干货 | 1 | 仅作行业背景，不作投保结论依据 |
| 兜底 1 | 离线快照（需自行导出，见第三节） | — | 标注「离线快照，2026-08-16」 |
| 兜底 2 | 联网搜索 | — | 「以下为联网公开信息，仅供参考」 |

**顺序不能乱**：IMA 四库任一命中就不必降级；四库全空 → 查离线快照；
离线快照也空 → 才联网。任何一层都没命中 → 如实说「库里没有现成观点，不敢乱讲」。

## 五、自检清单

首次使用跑一遍，缺哪补哪：

- [ ] WorkBuddy 已连接「ima知识库」连接器（路线 A / B 需要，路线 C 不需要）
- [ ] `config.json` 的 `kb_priority` id 已指向你有权访问的知识库
- [ ] `python scripts/kb_search.py "护工卡"` 能正常返回结果（验证离线快照）
- [ ] `yurenzhe-perspective`、`laoyu-client-grill`、`baolaiwu` 三个同伴技能已解压到 skills 目录
- [ ] 联网搜索可用（最后一层兜底）
